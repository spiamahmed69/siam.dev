JavaScript Basics for Beginners

JavaScript is the programming language of the web. HTML gives a page its structure, CSS gives it its look, and JavaScript gives it behaviour: menus that open, forms that validate, content that updates without reloading. If you want to build interactive websites, this is where it starts.

What Is JavaScript?

JavaScript runs in every modern browser, which makes it the most widely available programming language in the world. It is also the language of Node.js on the server, of React and other frameworks, and of tools like Firebase — so the basics you learn here carry a long way.

You do not need anything special to start: a text editor and a browser are enough. Create a file called script.js, link it at the end of your HTML body, and open the page.

Variables and Data Types

A variable stores a value you can use later. Use const for values that will not change and let for values that will. Avoid var in new code — it has confusing scoping rules that let and const fix.

const siteName = "SIAM.DEV";   // string
let visitCount = 0;             // number
let isDarkMode = true;          // boolean

visitCount = visitCount + 1;
console.log(siteName, visitCount);

JavaScript has a handful of basic types: strings, numbers, booleans, null, undefined, arrays and objects. The typeof operator tells you which type a value is, which is useful when something behaves unexpectedly.

Functions

A function is a reusable block of code that does one job. Give it a clear name, pass in what it needs, and return what it produces:

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Siam")); // "Hello, Siam!"

const add = (a, b) => a + b;
console.log(add(2, 3)); // 5

Arrow functions (the second example) are shorter and are used everywhere in modern code. Start with regular function declarations until you are comfortable, then adopt arrow functions gradually.

Arrays and Objects

An array is an ordered list; an object is a collection of named values:

const skills = ["HTML", "CSS", "JavaScript"];
console.log(skills[0]);        // "HTML"
console.log(skills.length);    // 3

const developer = {
  name: "SP Siam Ahmed",
  role: "Full Stack Web Developer",
  country: "Bangladesh"
};
console.log(developer.role);

Arrays come with powerful built-in methods — map, filter and forEach — that replace most manual loops once you learn them. For now, know that they exist; you will reach for them naturally as your code grows.

Conditions and Loops

Programs make decisions with if and repeat work with loops:

const score = 85;

if (score >= 80) {
  console.log("Excellent");
} else if (score >= 50) {
  console.log("Passed");
} else {
  console.log("Try again");
}

for (let i = 0; i < skills.length; i++) {
  console.log(skills[i]);
}

Use strict equality (===) instead of loose equality (==). Loose equality converts types silently and causes bugs that are hard to find; strict equality compares both value and type.

Events and the DOM

JavaScript becomes useful when it responds to the user. The DOM (Document Object Model) is the browser's live representation of your page, and events are how you listen to it:

const button = document.querySelector("#menu-btn");

button.addEventListener("click", function () {
  document.body.classList.toggle("menu-open");
});

This pattern — select an element, listen for an event, do something — is the heart of interactive web development. Read Understanding JavaScript DOM Manipulation for a deeper guide.

Where to Learn More

The most reliable reference is MDN JavaScript — complete, accurate and free. Read it alongside your own experiments: type every example, change one thing, and see what happens. That loop — read, try, break, fix — is how the language actually sticks.

Conclusion

JavaScript basics are not many: variables, functions, arrays, objects, conditions, loops and events. Learn those properly, build small things with them every day, and the frameworks will make sense when you reach them — because frameworks are just JavaScript, organised.
