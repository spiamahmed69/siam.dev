CSS Flexbox vs CSS Grid

By SP Siam Ahmed · Published 26 November 2026 · Updated 26 November 2026

Table of Contents

  • Flexbox vs Grid: The Key Differences
  • When to Use Each
  • Using Them Together

Flexbox and Grid are both layout tools, but they solve different problems. Flexbox arranges items in one direction — a row or a column. Grid arranges items in two directions at once — rows and columns. Knowing which one to reach for is the difference between a layout that is easy and one that fights you.

What Is Flexbox?

Flexbox (the Flexible Box Layout) is designed for one-dimensional layouts: a navigation bar, a row of buttons, a card with an icon and text. You set display: flex on a container, and its children become flexible items that can grow, shrink and align themselves along a single axis.

.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

The properties that matter most are justify-content (along the main axis), align-items (along the cross axis) and gap (space between items). With those three, most component layouts are done.

What Is CSS Grid?

Grid is designed for two-dimensional layouts: a whole page, a gallery, a dashboard, a card grid. You define rows and columns on the container, then place items into the cells — or let them flow automatically.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* Responsive without media queries: */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 20px;
}

The repeat(auto-fill, minmax(240px, 1fr)) pattern is one of the most useful lines in CSS: it creates as many columns as fit, each at least 240px wide, and it adapts to any screen width without a single media query.

Flexbox vs Grid: The Key Differences

  • Dimension: Flexbox is one-dimensional (a row or a column). Grid is two-dimensional (rows and columns together).
  • Control: Flexbox controls layout from the items outward — items decide their own size. Grid controls it from the container inward — the container defines the tracks.
  • Alignment: both offer powerful alignment, but Grid lets you align items to both axes at once.
  • Content vs layout: Flexbox works best when the content decides the layout; Grid works best when the layout decides where the content goes.

When to Use Each

Use Flexbox for navigation bars, button groups, form rows, centring a single item, and any component where items sit in a line. Use Grid for page layouts, card grids, galleries, dashboards and any design where items must line up in both directions.

A common mistake is forcing Grid to do a simple row of buttons, or forcing Flexbox to build a page with a sidebar and a header. Both can be done, but the code becomes harder to read and harder to change.

Using Them Together

The two are not rivals — they are teammates. A typical modern page uses Grid for the overall layout and Flexbox inside the components:

.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  gap: 24px;
}

.card {
  display: flex;
  flex-direction: column;
}

.card .actions {
  display: flex;
  gap: 8px;
  margin-top: auto;
}

That pattern — Grid outside, Flexbox inside — covers most real layouts. The MDN CSS documentation has complete guides to both, with interactive examples worth working through.

Conclusion

Ask one question when you start a layout: does this need one direction or two? One direction — Flexbox. Two directions — Grid. Use Grid for the page, Flexbox for the components inside it, and your layouts will stay simple, responsive and easy to maintain.
