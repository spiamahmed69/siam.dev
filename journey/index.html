My Journey

My Journey in Technology

My development journey is shaped by curiosity, practical learning and the desire to create useful digital experiences.

  1. June 2023

    First steps on GitHub

    I created my GitHub profile, Spsiamahmed, and began experimenting with HTML, CSS and JavaScript — small pages, small ideas, learning by building.

  2. 2024

    First portfolio sites

    I built my first portfolio websites and published them on GitHub Pages — my first experience of putting real work on the public web and sharing it with others.

  3. November 2026

    An intensive build period

    In a single month I designed, built and launched a whole set of live platforms: SP Calculator, SP Calendar, SP Weather, SP Academy, SP Books, SP Exam, SP Intelligence, Bangla Education, SP Marketplace and SP News. Each one taught me something new — Firebase, payments, exams, SEO, performance and publishing.

  4. November 2026

    SIAM.DEV launches

    This website — SIAM.DEV — becomes my official portfolio: a single, honest home for my projects, skills, writing and contact details.

The journey continues. The next step is always the same: build something real, publish it, learn from it. See what I am building now on the projects page.
